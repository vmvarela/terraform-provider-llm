# Contributing

Thanks for considering a contribution. All project content (code, comments,
documentation, examples, diagnostics, commit messages) must be in English.

## Requirements

- [Go](https://go.dev/) (per `go.mod`)
- [Terraform](https://developer.hashicorp.com/terraform/downloads) 1.13 or
  newer, for acceptance tests and example formatting

## Building and Testing

```sh
make build      # compile the provider
make test       # unit tests (httptest-based, no credentials or paid APIs)
make vet
make fmt-check  # gofmt + terraform fmt check
make testacc    # acceptance tests: TF_ACC=1 go test ./internal/provider/ -run TestAcc -count=1
```

Acceptance tests run real Terraform against in-process mock HTTP servers with
request counters. They never call a live LLM API and require no credentials.
Live endpoint compatibility is untested; per-backend verification must be
explicit and opt-in.

## Documentation

`docs/` is generated by `terraform-plugin-docs` (pinned in the `tools/` nested
module). Never hand-edit generated files: change schemas, descriptions, or
files under `examples/`, then regenerate:

```sh
make generate   # or: go generate ./...
```

Generated documentation must produce no diffs after regeneration. Format
examples with `terraform fmt -recursive examples/`.

## Submitting Changes

Before opening a pull request, verify:

```sh
go build ./...
go vet ./...
go test ./...
make fmt-check
make generate   # no diffs in docs/
terraform fmt -check -recursive examples/
```

Keep credentials, local credential files, Terraform state, and saved plans out
of tracked files. Do not assume ignore rules protect files that were already
tracked.
